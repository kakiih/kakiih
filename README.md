# 💼 Projetos em Destaque

## 🤖 Orquestrador de Bots Python
API backend desenvolvida em FastAPI para upload e execução segura de bots Python em containers Docker.

### Principais funcionalidades
- Autenticação JWT com refresh token rotativo
- Upload e validação de bots `.py`
- Execução isolada em containers Docker
- Controle de CPU, memória, timeout e logs
- Histórico de execuções
- Ownership por usuário
- Rate limiting
- Migrations com Alembic

### Stack
`FastAPI` • `Docker` • `PostgreSQL` • `SQLAlchemy` • `Alembic` • `JWT`
